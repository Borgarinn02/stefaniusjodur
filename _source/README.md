# Source material: scraped from the old stefaniusjodur.is

The old domain no longer resolves (checked 2026-11-24). Everything here comes from the
Internet Archive's Wayback Machine. Each file is the latest snapshot the archive has of that page or image.

## Layout
- `content/`: the main text of every page as Markdown (Icelandic, cleaned up). **Start here.**
- `recipients.json`: all 50 award recipients, 1970–2017, with name, year, photo, photo credit and bio.
  Spelling mistakes in names on the old site are corrected; the original spelling is kept in `nameOnOldSite`.
- `content/pages.json`: page titles and the images used on each page, with captions.
- `assets/img/`: portraits, photos of Stefanía, Anna Borg and Poul Reumert, the trophy image, the banner and the background.
- `assets/myndasafn/`: the photo gallery. Full-size images, plus thumbnails ending in `s` (for example `M2015As.jpg`).
- `pages/`: the original HTML, converted to UTF-8, kept for reference.
- `cdx-index.json`: the archive's list of every URL it captured from the site.

## Gaps
- **2017 recipients** (Stefán Karl Stefánsson, Steinunn Ólína Þorsteinsdóttir): the archive has no portrait and no bio. The old site only said "Í vinnslu" (in progress).
- **Selma Björnsdóttir (2012)**: no bio on the old site.
- **Gallery**: 6 full-size images were never archived (M2010M, M2012A, M2013E, M2014H, M2015E, M2016); only the small thumbnails survive.
- **No winners after 2017–18** appear in the archive. Recipients from 2018 onwards need to come from the fund itself.
- Image resolution: the archived photos are the old web sizes, so many are small (roughly 300–600 px wide).
